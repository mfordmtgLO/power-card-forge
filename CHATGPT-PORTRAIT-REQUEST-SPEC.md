# ChatGPT Portrait enhancement requests — workflow (Mike's design, 2026-11-05)

The case-by-case enhancement path (the "Maya path") as a tracked pipeline.
Default for every Forge character stays locked pencil sketch; this pipeline
is the ONLY way a character gains working Looks, and it is always
Mike-initiated work on portraits Mike commissions.

## Flow

1. **Request** — every Forge character sheet carries a button inside the
   sheet: "Request ChatGPT Portrait enhancement" (wording per Mike's ask:
   the button IS that specific request). Tapping it files a request for
   that character.
2. **Admin inbox** — requests land in Mike's Forge admin app (Google
   sign-in, Mike Ford admin). On opening the app, new character
   customizations are obvious at a glance (a visible new-requests
   signal/count) and held in a dedicated **"Chat GPT Portrait" draft
   stable** — separate from any player's Stable of 20.
3. **The work** — Mike completes the portrait work with ChatGPT, serves
   the finished portraits to Kendo, and Kendo wires them into the Power
   Card game's "Looks" for that character.
4. **Review + status** — Mike reviews the hair and skin combos. When he
   has approved them, he opens the character in the Chat GPT Portrait
   stable and changes its status from **draft** to **complete**.
5. **Push** — from the completed entry, "Push to <player>'s stable of
   20": the enhancement lands on the EXISTING character in that player's
   stable — it overwrites/enhances the original character's looks and
   does NOT consume a new stable slot.
